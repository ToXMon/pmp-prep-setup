# Use a mobile web app for the first release

- Date: 2026-11-24
- POC: PMP Prep Setup maintainer
- TL;DR: Ship a phone-first browser app with no sign-in, hosted scoring, or cross-device sync.

A native iOS app would add a build and signing setup before the first study session. A static web app can serve original drills over HTTPS and keep answers, self-scores, and imported notes on the device. Its trade-offs are per-browser progress and no App Store distribution. Revisit native iOS or account sync only after the drill loop proves useful.
