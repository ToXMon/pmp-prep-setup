# PMP Prep Setup

A mobile-first study coach covering all five PMP bootcamp sessions and a separate ethics track. It is a starter practice bank, not a full exam simulator or a predictor of passing.

## Start studying

Open the [study app](https://toxmon.github.io/pmp-prep-setup/). Choose a session, select one best answer, then check the rationale and open its source. Missed concepts return after a day and correct ones after three days. You can restart a track to practice it again. Progress stays in the current browser. The previous free-text activity is not migrated.

Search the built-in topic index without uploading documents. Results link to the pinned course PDFs and Code. The index contains original summaries and source locators, not full-text search of the decks, transcripts, or RAG chunks.

To run locally, serve this checkout with `python3 -m http.server 8080` and open `http://localhost:8080`. Run `node --test` for automated checks. No account or API key is needed.

## Public/private boundary

Commit only original practice, citation locators, code, and project docs. Do not commit course PDFs, raw transcripts or chunks, Zoom links, credentials, or study logs. This app makes no model calls.

## Study plan

Start with Session 4 and ethics, then mix the other sessions. Use a 40-hour initial budget with a fresh diagnostic and timed mocks outside this question bank. See the [crosswalk backlog](docs/crosswalk.md) and [glossary](GLOSSARY.md).
