# PMP Prep Setup

A mobile-first study coach for original PMP practice. Start with Session 4 cost of quality, then add ethics in week one. This starter is not a full diagnostic, a complete slide crosswalk, or a predictor of passing.

## Start studying

Open the [study app](https://toxmon.github.io/pmp-prep-setup/) if GitHub Pages is enabled. Otherwise, serve this checkout locally with `python3 -m http.server 8080` and open `http://localhost:8080`. No account or API key is required. The layout works on phones; desktop and phone progress are separate.

1. Pick Session 4 or Ethics.
2. Answer before revealing the source-cited rubric.
3. Self-score. The app offers a different scenario on the same concept when it is due, if one exists.
4. To search your own corpus, select the local transcript, RAG chunk, and callout Markdown files for all five sessions. Nothing is uploaded; reselect them after reloading. Search hits are not verified slide matches.

From this checkout, run `node --test` to check search and scheduling. The app uses plain HTML, CSS and JavaScript.

## Public/private boundary

Only original practice, citation locators, code, and project docs belong here. Never commit course PDFs, raw transcripts or chunks, Zoom links, credentials, or study logs. Imported text stays in tab memory. The app stores only self-scores and review dates in your browser; it does not save your written answers. It does not make model calls.

## Study plan

Budget about 10 hours per week and use 40 hours as a first checkpoint, not a pass threshold. February 2027 is tentative. Start with a fresh diagnostic outside this practice bank, drill Session 4 and ethics in week one, and use fresh timed mocks to decide whether to book. Keep other PMI outline topics in the queue.
